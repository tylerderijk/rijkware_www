# Social Media Sharing Image

## Required File: og-image.jpg

Please create an image file named `og-image.jpg` in this directory with the following specifications:

- **Dimensions**: 1200 × 630 pixels (optimal size for most social platforms)
- **Format**: JPG
- **Content**: Should include the Rijkware logo and possibly a tagline
- **File size**: Keep under 1MB for faster loading

This image will be used for social media sharing on platforms like Facebook, Twitter, and LinkedIn. The meta tags in `index.html` are already configured to use this image.

## Example Usage

```html
<meta property="og:image" content="https://rijkware.com/og-image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:image" content="https://rijkware.com/og-image.jpg">
```

These tags are already added to the HTML. You just need to create the actual image file.
